# 规则说明（欢乐斗地主规则）

本文档是规则的唯一依据：引擎（`engine/rules`、`engine/game`）、玩法说明页面和测试都以它为准。

## 牌与点数

一副 54 张：3–10、J、Q、K、A、2 各四张，另有小王、大王。
点数从小到大：3 < 4 < … < K < A < 2 < 小王 < 大王。花色不影响大小。

顺子、连对、飞机只能由 3–A 组成，2 和王不能参与。

|---|---|---|
| 单张 | x | |
| 对子 | xx | 两张王不算对子（那是王炸） |
| 三张 | xxx | |
| 三带一 | xxx + y | |
| 三带一对 | xxx + yy | |

| 连对 | ≥3 对连续对子 | |

| 飞机带翅膀（单） | n 组连续三张 + n 张单牌 | 单牌可以重复，如 333444+55 |
| 飞机带翅膀（对） | n 组连续三张 + n 对 | 各对点数不同 |
| 四带二 | xxxx + 两张单牌 | 两张可以是一对，如 5555+33 |
| 四带两对 | xxxx + 两对 | 两对点数不同 |
| 炸弹 | xxxx | |
| 王炸 | 小王 + 大王 | 最大的牌 |

一次最多出 20 张。

### 带牌约束

- **K1**：带牌不能与主体（三张、四张或飞机中任何一组）同点数。例如 33334444 不合法，3334444+5 也不合法。
- **K2**：带牌里不能同时有小王和大王；只带一张王可以。
- **K3**：带牌里不能有四张同点数的牌。例如 3333+5555、333444555666+7777 都不合法。

## 大小比较

- 王炸压一切。
- 炸弹压一切非炸弹；炸弹之间比点数。
- 其余牌型必须类型相同、组数（顺子张数、连对对数、飞机组数）相同，并且主体的点数更大才能压。带牌不参与比较。
- 四带二、四带两对不是炸弹，不翻倍，也不能压其他牌型。

### 一手牌有多种解释时

某些牌组可以有多种读法，例如 333444555666 既是 4 组飞机，也是 3 组飞机带 3 张单牌（翅膀是 666 或 333）。

- 出牌时会同时声明牌型，引擎校验这个声明是牌组的合法读法。
- **首出**：先比组数，组数多的优先；再比有无带牌，不带牌的优先；最后比点数，点数高的优先。所以 333444555666 首出时算 4 组飞机。
- **跟牌**：只考虑与上家类型、组数相同且点数更大的读法，取点数最高的那个。

## 叫地主与抢地主

每局每人 17 张，留 3 张底牌，随机选一人先叫。

1. **叫地主**：从首叫者开始依次选择“叫地主”或“不叫”。三人都不叫则重新发牌。
2. **抢地主**：有人叫地主后，排在他后面、还没表态的人依次选择“抢地主”或“不抢”。选过“不叫”的人不能再抢。每人最多抢一次，每抢一次倍数 ×2。
3. **反抢**：只要有人抢过，叫地主的人最后还有一次机会“抢地主”（再 ×2）。选择不抢时，最后一个抢的人当地主。
4. 没人抢时，叫地主的人当地主；如果叫地主的是最后一个表态的人，他直接当地主。

| 过程（A→B→C 依次行动） | 地主 | 倍数 |
|---|---|---|
| A叫 B不抢 C不抢 | A | ×1 |
| A叫 B抢 C不抢 A抢 | A | ×4 |
| A叫 B抢 C抢 A不抢 | C | ×4 |
| A叫 B抢 C抢 A抢 | A | ×8 |
| A不叫 B叫 C抢 B不抢 | C | ×2 |
| A不叫 B不叫 C叫 | C | ×1 |
| 三人都不叫 | 重新发牌 | – |

地主拿走 3 张底牌，底牌对所有人公开。

## 加倍

地主确定后，三人同时选择“加倍”或“不加倍”，在所有人都选完之前互相看不到。地主加倍对两个农民的输赢都生效；农民加倍只影响自己和地主之间的输赢。之后由地主先出牌。

## 出牌

地主先出，按座位轮流（玩家 → 右边 → 左边）。轮到的人可以出一手能压过当前牌的牌，也可以“不出”。连续两人不出后，最后出牌的人重新自由出牌；自由出牌时不能不出。

谁先出完手牌，谁那一方获胜：地主单独一方，两个农民一方。

## 翻倍与结算

- 公共倍数 = 2^（抢地主次数 + 炸弹数 + 春天/反春），王炸算一个炸弹。
- **春天**：地主获胜，两个农民一张牌都没出过。
- **反春**：农民获胜，地主只出过第一手牌。
- 每个农民与地主之间的输赢 = 底分 × 公共倍数 × 地主加倍(×2) × 该农民加倍(×2)。
- 地主的输赢是两个农民输赢之和。

封顶（保证零和、没有人被扣成负数）：

1. 每个农民的输赢不超过自己的金币。
2. 如果两个农民的输赢加起来超过地主的金币，两份按比例缩小到地主的金币数（向下取整）。

结算界面同时显示未封顶的原始数额和实际输赢。
