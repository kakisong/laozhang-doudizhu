# 背景音乐

游戏内置一首原创器乐循环《欢乐牌桌》，资源位于
`app/src/main/assets/music/table_theme.m4a`，断网也能播放，不需要下载或音乐服务。

这首音乐采用 114 BPM、4/4 拍、24 小节的 D 大调五声音阶旋律，长度约 50.53 秒。
短而明亮的拨弦与柔和木琴式音色带来轻松欢快的听感，跳跃旋律配合反拍键盘和弦、
根音与五度交替低音，以及轻巧的手鼓和刷奏节拍。六组乐句包含上行跳进、切分节奏与
问答变化，适合在牌桌上长时间循环。音色保留柔和起音，音乐源文件预留音量余量，
应用内再以较低音量播放，给普通话报牌和提示留出空间。

## 来源与使用

旋律、和声、音色合成与编排完整保存在 `scripts/generate_music.py` 中，
是为本项目制作的原创内容。没有下载或使用第三方录音、采样、已有歌曲旋律，
也没有调用在线音乐生成服务。音乐文件与生成脚本作为项目资产一起维护，
遵循项目的 [MIT 许可证](../LICENSE)；
第三方 AI 模型或语音资产的许可不适用于这首音乐。

## 重新生成

需要 Python 3.9 或更新版本、NumPy，以及 macOS `afconvert` 或带 AAC 编码器的
`ffmpeg`。生成器不联网，固定随机种子 `20261003`，可重现相同的 PCM 音乐。
AAC 文件的字节级结果可能随编码器或系统版本变化。

在项目根目录运行：

```sh
python3 scripts/generate_music.py --wav-output /tmp/doudizhu-table-theme.wav
```

输出包括：

- `app/src/main/assets/music/table_theme.m4a`：随安装包发布的 AAC-LC 音乐。
- `app/src/main/assets/music/catalog.json`：来源、生成参数、校验和及音频检查结果。
- `/tmp/doudizhu-table-theme.wav`：可选的无损试听文件，不打包进应用。

只生成无损试听文件、不编码或改动应用资产：

```sh
python3 scripts/generate_music.py --no-encode --wav-output /tmp/doudizhu-table-theme.wav
```

macOS 的 AAC 编解码服务在受限进程沙箱中可能不可用；这种情况下可在普通终端运行，
或先使用 `--no-encode` 检查音乐。生成器会拒绝解码后长度变化、削波或循环接缝过大的
压缩文件，不会静默接受编码器额外添加的尾部静音。

## 循环与质量检查

合成器将每个乐音的尾音及房间反射折回循环开头，让上一轮最后的乐句自然衔接下一轮。
首尾没有淡出、停顿或重复的开场段。播放编码文件时应使用原文件的循环功能，
保留 M4A 中的 AAC 起始延迟和尾部裁剪信息。

当前随包资产的检查结果（详细数据以 `catalog.json` 为准）：

| 项目 | 结果 |
| --- | --- |
| 格式 | AAC-LC，44.1 kHz，立体声 |
| 目标码率 / 文件大小 | 96 kbps / 576,083 字节（约 563 KiB） |
| 解码长度 | 2,228,211 帧，与原始 PCM 完全一致 |
| 时长 | 50.526327 秒 |
| 原始峰值 / RMS | -9.734 / -22.000 dBFS |
| 解码峰值 / RMS | -9.664 / -22.004 dBFS |
| 原始 / 解码削波样本 | 0 / 0 |
| 解码循环接缝最大样本跳变 | -59.428 dBFS |
| 编码往返信噪比 | 32.734 dB |

接缝跳变明显小于音乐内部的正常样本变化（最大约 -28.87 dBFS），避免首尾突跳。
生成器自动检查这些指标；手机上的最终听感、语音与音乐的相对音量仍应在真机上试听。
